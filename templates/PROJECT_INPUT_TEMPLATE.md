# VIDEO PROJECT INPUT

ضع الملفات داخل مجلد المشروع، واستخدم أسماء واضحة.

## الملفات الأساسية
- `input/audio/voiceover.wav` — الصوت النهائي (يمكن استخدام mp3/m4a).
- `input/text/voiceover.txt` — النص الصوتي المطابق حرفياً.
- `input/text/video_content.md` — نص الفيديو/السيناريو/المادة المطلوب تمثيلها.

## ملفات اختيارية
- `input/references/` — صور أو لقطات مرجعية أو هوية بصرية.
- `input/brand/` — شعارات وخطوط وألوان وملفات العلامة.
- `input/notes/project_notes.md` — تعليمات خاصة.
