# ZORO VIDEO DIRECTOR PRO

**Universal AI Video Production Director — Claude Code + Claude Web**

نظام إخراج وإنتاج فيديوهات متعدد الأنواع. مهمته توجيه Claude لتحويل حزمة محتوى تحتوي على الصوت والنص الصوتي ونص الفيديو إلى إنتاج بصري متكامل، مع إنشاء العناصر البصرية الناقصة بدلاً من مطالبة المستخدم بتوفيرها.

## مبدأ العمل الحاكم

- **المستخدم + ChatGPT:** يجهزان الفكرة والبحث والنص الصوتي والصوت الفعلي ونص الفيديو ومخطط المحتوى، ثم يسلّمان الحزمة.
- **Claude:** المخرج البصري والمنفذ الإنتاجي. يحلل المحتوى، ويخطط المشاهد، وينشئ الصور والرسوم والخرائط والمخططات والشخصيات عند غيابها، ويصمم الحركة والأنيميشن والتركيب والترجمة والمونتاج والرندر والفحص.
- لا يُطلب من المستخدم توفير صور المشاهد كشرط للبدء. الصور المرفوعة مراجع اختيارية فقط.
- لا يدّعي Claude امتلاك مولّد صور أو فيديو غير متاح في بيئته. إذا لم تتوفر أداة توليد، يستخدم بدائل محلية/برمجية أو مصادر مرخصة، ويوضح أي قيد حقيقي قبل اعتماد النتيجة.

## البدء

### Claude Code
1. افتح المستودع في Claude Code.
2. تأكد أن ملف `CLAUDE.md` في جذر المشروع.
3. ارفع/ضع ملفات المشروع في مجلد `input/` وفق `templates/PROJECT_INPUT_TEMPLATE.md`.
4. اطلب: `ابدأ إنتاج الفيديو وفق تعليمات ZORO VIDEO DIRECTOR PRO`.
5. اتبع بوابات الجودة في `QUALITY_CONTROL.md`.

### Claude Web
1. ارفع ملفات التعليمات الأساسية: `CLAUDE.md` و`DIRECTOR_SYSTEM.md` و`WORKFLOW.md` و`QUALITY_CONTROL.md`.
2. ارفع حزمة الفيديو: الصوت، النص المطابق، نص الفيديو، وأي مراجع اختيارية.
3. الصق التعليمات الموجودة في `CLAUDE_WEB_PROMPT.md`.
4. اطلب من Claude إرجاع ملفات المشروع والنتيجة أو حزمة قابلة للتنزيل بحسب الأدوات المتاحة في جلسة Claude.

## بنية الحزمة

- `CLAUDE.md` — مدخل التعليمات الدائم لـ Claude Code.
- `DIRECTOR_SYSTEM.md` — فلسفة الإخراج وقواعد القرار البصري.
- `WORKFLOW.md` — مراحل الإنتاج والتسليم.
- `QUALITY_CONTROL.md` — اختبارات القبول ومنع إعلان النجاح المبكر.
- `SCENE_SCHEMA.json` — عقد بيانات موحد للمشاهد.
- `CLAUDE_WEB_PROMPT.md` — مطالبة تشغيل Claude Web.
- `templates/` — قالب تسليم المواد ومثال بنية المشروع.
- `.claude/skills/video-production/SKILL.md` — مهارة إنتاج قابلة للاستدعاء في Claude Code.

## تنبيه واقعي
هذه الحزمة توجه Claude ولا تمنح الحساب تلقائياً أدوات توليد صور أو فيديو أو صوت. على Claude فحص الأدوات المتاحة فعلياً، واختيار مسار إنتاج قابل للتنفيذ، وتوثيق أي اعتماد خارجي أو قيد تقني.
